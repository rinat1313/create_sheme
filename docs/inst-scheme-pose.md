# Значки и поза объектов на схеме (эталон Inst)

Папку `ПО` этот документ не меняет. Значки скопированы в `web/assets/inst-icons/`.

## Откуда картинки

| Сборка | Что внутри |
|--------|------------|
| `Rsuog.Udt.Images.dll` | `ImageLocator` / `ImageResourceHelper`: каталоги `technologyimages` (объекты схемы) и `images` (лента). Размеры `ImageSize` 16 и 32. |
| `Rsuog.Udt.Model.Domain.Visuals.dll` | Доп. значки типов, которых нет в `technologyimages` (сглаживающий клапан, лупинг, врезка и др.). |
| `Rsuog.Desktop.Wpf.Images.dll` | Заглушка оболочки. |
| `Modules/...VisualEditor.dll` | Картинки окон редактора (в каталоге лежат, на холсте не используются). |

На холсте в режиме «Детальный символ» берётся файл `*_32.png` по типу объекта. Если файла нет — прежний векторный знак.

## Позиционирование (модель Visuals)

Ключевые типы: `VisualObject`, `VisualPoint`, `VisualCanvas`, `MathFactory`, декларации `*Declaration`.

Поля объекта схемы, которые задают позу:

1. **Якорь** `AnchorPoint` (X, Y) — `Location` / `LocationTransform`. Точка привязки знака на схеме.
2. **Ломаная** `Points` — относительные `VisualPoint`; мир = якорь + точка. Трубы рисуются только ломаной. У оборудования с несколькими точками ломаная — контур потока, знак остаётся на якоре.
3. **Угол** `Angle` — поворот `InnerTransform` вокруг якоря (градусы, как в XML).
4. **Отражения** `IsHorizontalReflected`, `IsVerticalReflected` — масштаб −1 по оси (`IsHorizontalReflectable` / `IsVerticalReflectable` на типе).
5. **Реверс** `IsReversed` — дополнительное зеркало по оси потока (как горизонтальное).
6. **Масштаб вида** в Inst: `ViewScale` / `ActualScale` холста. У нас координаты XML 1:1 (`layoutScale = 1`), размер знака — 32 px × `objectSymbolScale` (сейчас 1.2, общий коэффициент под стык с Inst).
7. **Смещение типа** из «Отображение» (`offsetX` / `offsetY`) кладётся поверх якоря.

Порядок преобразования, как у группы WPF вокруг якоря:

`translate(якорь) → rotate(Angle) → scale(sx, sy) → translate(−якорь)`

`CompensationInnerTransform` в Inst компенсирует поворот относительно точек соединения; у нас точки ломаной уже в мировых координатах XML и в эту группу не входят.

Подписи на схеме по-прежнему из панели «Отображение», не из `GraphicLabel` Inst.
