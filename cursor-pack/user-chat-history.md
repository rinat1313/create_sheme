Добавь skill для этапа Проверка задач:

тестировщики проверяют выполненные задачи, если что то не работает, отправляют информацию для lead на необходимость переделки. lead по не работающим задачам проводит процедуру исправления, анализируется как задача сделана, что не сделано, где исполнитель наврал в отчёте, задача отправляется на переделку и повторную проверку.

Если все тесты пройдены удачно. Собирается информация о проделанной работе для дальнейшего этапа, документы с внесёнными изменениями. Важный момент, Тестировщики не вносят изменения в документацию и код.

## 22.10.2026, 10:46 — группа Специалисты

Группа пользователей Специалисты:
аналитик - анализирует ТЗ на соответствие приложению, в каком направлении мы двигаемся, сложность задач.
архитектор - разбирается в архитектурах, очень хорошо знает новые технологии, умеет их внедрять. топовый инженер в IT сфере.
ui/ux дизайнер - хорошо разбирается в дизайне, современных стилях оформления приложений, соблюдает основные паттерны разработки дизайна.
специалист по информационной безопасности - специализируется на информационной безопасности, защищает от утечек информации, возможностей взлома.
алгоритмист - очень хорошо разбирается в высшей математики, алгоритмах, теориях вероятности и физике.

## Как это легло в файлы

| Формулировка пользователя | Куда попало |
|---------------------------|-------------|
| skills по этапам главного skill | `skills/tz-intake` … `tz-report`, `skills/tz-workflow` |
| одна ветка для актуальных skills/rules/subagents | `rules/cursor-config-on-main.mdc` |
| проверка задач, 10 попыток, тестеры не правят код | `skills/tz-verify` |
| документация, help, отдельная задача, простой язык | `skills/tz-docs`, `skills/user-docs`, `skills/tz-writers` |
| отчёт lead | `skills/tz-report` |
| убрать subagents кроме lead | сначала только `agents/lead.md`; позже снова расширено |
| Специалисты (роли) | `skills/tz-specialists` + агенты `analyst` … `database` |
| Исполнители | `skills/tz-executors` + `backend`, `frontend`, `sql`, `devops` |
| Тестировщики | `skills/tz-testers` + `qa-tester`, `manual-tester`, `sql-tester` |
| Технический писатель | `skills/tz-writers` + `technical-writer` |
| все в группах — субагенты | файлы в `agents/`, вызов через Task из `lead` |
